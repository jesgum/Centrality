## TGlauberMC

### Pb profiles summary
  - Pb: Charge density from <sup>207</sup>Pb with point nucleons
  - Pb*: Charge density from <sup>208</sup>Pb with point nucleons
  - pn: Separate proton and neutron density profiles
  - rw: Reweighting to correct for center-of-mass recentering 
  - HN: "hard nucleon size", nucleons given spatial extend instead of being point-like
